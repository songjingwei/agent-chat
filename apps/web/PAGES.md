# 前端页面规划 (MVP)

本文档定义了 Agent Chat 前端应用的核心页面结构、功能描述及开发优先级。

## 1. 核心模块划分

### 发现与概览 (Discovery & Overview)
*   **广场**: 发现公共 Agent 并发起对话。
*   **列表**: 管理个人的历史对话。

### 对话核心 (Chat Core)
*   **聊天室**: 核心交互区，支持双机对话展示、历史回放及人工介入。

### Agent 管理 (Persona Management)
*   **生成器**: 从用户资料自动生成 Persona。
*   **编辑器**: 手动精修 Agent 的性格与设定。

### 结果与反馈 (Reports & Feedback)
*   **报告**: 对话后的总结与匹配建议。

---

## 2. 页面清单

| 页面路径 | 功能描述 | 优先级 | 核心交互 |
| :--- | :--- | :--- | :--- |
| `/` | **广场页**：浏览可用的 Agent | P1 | 列表展示、搜索、点击发起会话 |
| `/sessions` | **会话列表**：管理我的历史聊天记录 | P1 | 分页列表、状态标识（进行中/已结束） |
| `/sessions/$id` | **聊天室**：对话主战场 | **P0** | 实时消息流、人工消息输入、回放控制 |
| `/personas` | **我的 Agent**：查看我创建的 Agent | P1 | 卡片列表、删除/编辑入口 |
| `/personas/create` | **创建页**：资料转 Agent | **P0** | 表单/文件上传、生成态展示 |
| `/personas/$id/edit` | **编辑页**：精修 Agent 设定 | P1 | 复杂的 Persona 字段编辑 |
| `/reports/$id` | **总结报告**：查看匹配结果 | P1 | 结构化报告展示、操作建议 |
| `/auth/login` | **登录页**：身份识别 | P2 | 最小化登录（Magic Link/Device ID） |

---

## 3. 开发路线与 DoD (Definition of Done)

### 第一阶段：P0 核心闭环 (Day 11)
*   **重点**: `/personas/create` -> `/sessions/$id`。
*   **DoD**: 用户能上传一段资料生成 Agent，并看到两个 Agent 开始对话。

### 第二阶段：P1 体验补齐 (Day 12)
*   **重点**: `/` (广场), `/sessions` (列表), `/reports/$id` (总结)。
*   **DoD**: 用户能从广场选人开聊，聊完能看到一份有价值的总结报告。

### 第三阶段：P2 账户与设置 (Day 14)
*   **重点**: `/auth/login`, 个人中心。
*   **DoD**: 支持跨设备同步会话记录。

---

## 4. 技术约定
1.  **路由**: 必须使用 `TanStack Router` 定义在 `src/routes/` 目录下。
2.  **状态**: 数据请求使用 `TanStack Query`，确保加载态和错误态处理。
3.  **UI**: 优先使用现有的 `styles.css` 定义的视觉变量（如 `--sea-ink`, `--lagoon`）。
