## 实际完成

### 1. Admin 管理后台 (`apps/admin/`)
- 新增 Next.js 15 应用（`@agent/admin`，端口 3002），使用 Ant Design 5 + TanStack Query + Zustand。
- 实现 10+ 页面：Dashboard（统计概览）、用户/Persona/会话/消息/报告/记忆管理、审计日志、系统配置、登录。
- `AuthGuard` + `AdminLayout` 侧边栏导航。
- 中英文 i18n 支持。

### 2. Admin API 路由层 (`apps/api/src/modules/admin/`)
- 9 个路由模块：auth、users、personas、sessions、messages、reports、memory、config、stats。
- `adminAuthMiddleware`：JWT 验证，区分 admin/user token，注入 `adminId` / `adminRole`。
- 用户封禁/解禁、Persona 推荐/取消、系统配置 CRUD、审计日志查询等完整管理能力。

### 3. Admin 认证服务 (`admin-auth.service.ts`)
- bcrypt 密码验证、JWT access + refresh token 双 token 机制。
- refresh token 存储为 SHA-256 hash，支持撤销和过期检查。
- 初始 admin 种子脚本（`seed-admin.ts`）。

### 4. Persona Pair Insight 服务 (`pair-insight.service.ts`)
- 对话后自动计算 persona 对关系快照（balance score、depth score、repeat penalty）。
- 标准化 pair key（`low_id < high_id`），确保每对 persona 一条记录。
- 输出中文 affinity label（初有回响 / 渐生好感 / 颇有默契 / 心有灵犀 / 灵魂共振）。
- 设计文档：`docs/discovery-relationship-marker.md`。

### 5. 数据库变更
- 新增 5 张表：`admin_users`、`admin_audit_logs`、`admin_refresh_tokens`、`system_configs`、`persona_pair_insights`。
- 2 个新迁移文件：`0001_nifty_menace.sql`、`0002_known_krista_starr.sql`。
- `persona_pair_insights` 通过 CHECK 约束保证 pair key 归一化。
