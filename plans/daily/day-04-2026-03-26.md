## 实际完成
- **状态机骨架**：新增 `AgentStateMachine`，支持 `idle/thinking/speaking/archiving/failed` 状态流转和 transition 记录。
- **结构化输出**：新增 Runtime JSON Schema（Thought/Response/MemoryCandidate）及解析器，支持：
  - 原始 JSON 解析；
  - 从非纯 JSON 文本中提取首个 JSON 对象；
  - Schema 校验失败可追踪错误信息。
- **Prompt 工程**：新增 `PromptManager`，支持 Persona、记忆（按权重排序）和消息历史拼装；实现 token 粗估与上下文裁剪。
- **执行引擎**：新增 `AgentRuntimeEngine`，支持：
  - 多次尝试（retry）；
  - 输出长度超限/解析失败/模型异常 fallback；
  - 生成统一 `RuntimeTurnResult`（含 message/memoryWrites/transitions）。
- **API 接入准备**：在 `apps/api` 新增 `RuntimeService` 并接入 `createServices`，提供调用 Runtime 的统一占位入口。
- **包脚本升级**：`@agent/runtime` 从占位脚本切换为真实 `dev/build/test/typecheck` 流程。
