# 计划管理说明

本目录用于管理 `agent chat` 的开发计划、每日执行进度和计划调整记录。目标是让你在每一天都清楚：
1. 今天做什么。
2. 是否达标。
3. 明天接什么。
4. 计划是否要调整。

## 文件说明
- `master-plan.md`：主计划（前置知识 + Day1-Day15 详细目标）。
- `progress-tracker.md`：每日执行跟踪（状态、阻塞、下一步）。
- `change-log.md`：计划调整记录（为什么改、改了什么、影响什么）。
- `daily-template.md`：每日复盘模板（复制后填写）。
- `daily/`：每日记录文件目录（建议命名：`day-01-2026-03-23.md`）。
- `../docs/jujutsu-workflow.md`：版本控制工作流（`jj` 优先）。

## 建议更新频率
- 每天开始前：更新 `progress-tracker.md` 的“今日目标”。
- 每天结束后：补充实际结果、阻塞点、次日第一步。
- 任何计划变更：同步写入 `change-log.md`。

## 维护规则
- 所有日期使用绝对日期（例如 `2026-03-23`），避免“今天/明天”歧义。
- 只记录事实和决策，不写模糊描述。
- 如果目标未达成，必须写“未达成原因 + 修正动作”。
